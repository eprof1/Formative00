Exercise 1 — Verify Ollama + Pull the Course Model

Goal: Verify Ollama is available in PowerShell 7 and pull the course model qwen2.5-coder:3b.

  1. Open PowerShell 7 (search: pwsh).
  2. Run the commands below:
ollama --version
ollama list
ollama pull qwen2.5-coder:3b
ollama list

If you see the model in ollama list, you are ready for the next steps.

Exercise 2 — Install Node.js 22+ (WinGet) + Verify

Goal: Install Node.js 22+ using WinGet and verify node and npm are available.

  1. In PowerShell 7, install Node.js 22:
winget install -e --id OpenJS.NodeJS.22

Close PowerShell after the install finishes, then open a new PowerShell 7 window so PATH updates apply.

  1. Verify Node and npm:
node -v
npm -v
where.exe node
where.exe npm

Exercise 4 — Start Clawdbot + Open the Local Dashboard

Goal: Start the Clawdbot integration through Ollama and open the local dashboard.

Required: Use the integration name shown by ollama launch. On many systems it is clawdbot (not openclaw).
  1. First, confirm the integration name list:
ollama launch
  1. Start Clawdbot (use the name you see in the list):
ollama launch clawdbot
  1. Open the local dashboard in your browser:
http://127.0.0.1:18789/
  1. In the dashboard, run this test prompt:
In exactly 3 bullet points, explain what a Python function is. Then give a tiny function example.

Exercise 5 — Use the “Debug Workflow” (AI-Assisted, Student-Owned)

Goal: Practice a repeatable workflow that improves your understanding of Python debugging.

In the dashboard chat, copy/paste a small Python error you encountered (from a lab, exercise, or your own practice code) and use this exact workflow:

  1. Explain: Ask for a one-sentence explanation of the error.
  2. Locate: Ask which exact line caused it and what the key variable types are.
  3. Fix options: Ask for two small fixes and why each works.
  4. Reflect: Write your own explanation of what you changed and why (in your words).

Use this exact prompt (paste into the dashboard): 

I am learning Python. Do NOT rewrite my whole program.
1) Explain my error in one sentence.
2) Tell me the exact line that caused it and what Python thinks the variable types are at that moment.
3) Give TWO small fixes and explain why each works.
Here is my code and error:
<PASTE CODE>

<PASTE ERROR TRACEBACK>
